## Earth Movements Simulator

An interactive 3D web application that simulates the Earth's rotation on its axis and revolution around the Sun. 

WebGL was used to create the 3D graphics and animations. JavaScript handled the application logic and user interactions. HTML and CSS were used for structuring and styling the user interface. Pipeline included Earth and Sun meshes, rotation and revolution mechanics, textures for realistic visuals, camera and lighting and user controls for real-time adjustments. An interesting detail is that Earth's night and day textures are blended to create a realistic transition between day and night on the Earth's surface.

The results of this project demonstrate the capabilities of WebGL for creating engaging and educational 3D web applications, and it serves as a resource for anyone interested in learning about the Earth's movements.
